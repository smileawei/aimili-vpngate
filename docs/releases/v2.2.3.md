# AimiliVPN V2.2.3

新增 Web HTTP/SOCKS5 代理认证配置，保留 V2.2.2 的节点 TCP 延迟测量与 Web 上游代理设置。

## 更新内容

- Web「代理设置」新增认证开关、代理用户名和密码，默认端口为 `7929`，HTTP CONNECT 与 SOCKS5 共用凭据。
- 代理凭据与 Web 登录账号独立；保存后立即用于新连接，已有连接继续使用。
- 配置保存在 `data/ui_auth.json`，重启、重建容器后保留；密码不会回显，留空保留原值，关闭认证后无需账号密码。
- Web 保存的配置优先于 `LOCAL_PROXY_USER` / `LOCAL_PROXY_PASS`，从未保存该项配置时仍沿用环境变量；关闭认证也不会重新启用环境变量中的凭据。
- 用户名、密码各限 1～255 个 UTF-8 字节，拒绝控制字符，用户名不能包含冒号；支持中文凭据比较。

## 升级

保留已有 `data/` 目录，使用本版本的 Compose 配置执行：

```bash
SOFTETHER_IMAGE_TAG=2.2.3 docker compose -f compose.ghcr.yaml pull
SOFTETHER_IMAGE_TAG=2.2.3 docker compose -f compose.ghcr.yaml up -d
```

如需固定版本，在 `.env` 设置 `SOFTETHER_IMAGE_TAG=2.2.3`。
更新本身不会自动启用代理认证；请在 Web「代理设置」中配置并保存，再将相同账号密码填入代理客户端。
从旧版预置上游地址的 Compose 升级时，请参阅 [V2.2.1 升级说明](v2.2.1.md)。
