# AimiliVPN V2.2.1

SoftEther 节点连接上游代理现在可以在 Web 后台配置，新部署默认直连。

## 使用方法

- 打开右上角管理菜单 → **代理设置 → 节点连接上游代理**。
- 填写 `socks5://主机:端口` 或 `http://用户名:密码@主机:端口`，也支持 SOCKS4 和 SOCKS5h；特殊字符需要 URL 编码。
- 保存后服务自动重启并重新建立连接，节点检测、主连接和热备统一使用新配置。
- 已配置时输入框留空会保留原值；勾选 **清除已配置的上游代理，改为直连** 可恢复直连。

配置保存在挂载目录的 `data/ui_auth.json`，文件权限为 0600，Web 不回显代理地址及密码。
Web 保存的配置优先于 `SOFTETHER_UPSTREAM_PROXY` 环境变量，清除后也不会恢复环境变量中的代理。
该设置适用于 SoftEther 后端。

## 升级

保留已有 `data/` 目录，使用本版本的 Compose 配置执行：

```bash
SOFTETHER_IMAGE_TAG=2.2.1 docker compose -f compose.ghcr.yaml pull
SOFTETHER_IMAGE_TAG=2.2.1 docker compose -f compose.ghcr.yaml up -d
```

如需固定版本，在 `.env` 设置 `SOFTETHER_IMAGE_TAG=2.2.1`。
新 Compose 移除了旧版预置的内网上游地址。旧部署如需继续使用原上游，升级前请在 `.env` 显式设置 `SOFTETHER_UPSTREAM_PROXY`，或升级后在 Web 重新填写。
若继续使用旧 Compose，其原有默认地址仍会作为初始值，可在 Web 中清除。
